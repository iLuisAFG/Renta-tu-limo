# Renta tu limo | Lujo Sobre Ruedas 👑

Plataforma web de ultra lujo para servicio exclusivo de renta de limusinas y transporte ceremonial en México (Bodas VIP, XV Años exclusivos, eventos corporativos, galas y traslados ejecutivos).

---

## 🌟 Características

- **Diseño Editorial & Nocturno:** Paleta carbón/obsidiana con acentos oro champán, basada en principios de alta costura automotriz.
- **Tipografía de Alto Contraste:** *Cormorant Garamond* para titulares monumentales y *Plus Jakarta Sans* para lectura de interfaz.
- **Galería Coverflow 3D:** Carrusel interactivo con perspectiva tridimensional, acelerado por hardware y con física de arrastre e inercia.
- **Cotizador Concierge VIP:** Configuración instantánea sin fricción que genera y envía solicitudes preformateadas directamente a WhatsApp.
- **Accesibilidad y Rendimiento:** Contraste WCAG AA verificado, compatibilidad con `prefers-reduced-motion` y rendimiento optimizado a 60/120 FPS.

---

## 🛠️ Stack Tecnológico

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones:** [Motion / Framer Motion](https://motion.dev/)
- **Iconos:** [Lucide React](https://lucide.dev/)

---

## 🚀 Instalación y Desarrollo Local

```bash
# Clonar el repositorio
git clone https://github.com/iLuisAFG/Renta-tu-limo.git
cd Renta-tu-limo

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
